# РЕКОМЕНДАЦИИ ПО ФОТОГРАФИЯМ ДЛЯ ВЫСТАВКИ

## 📸 ГЛАВНЫЙ ЭКРАН (HERO SECTION)
**Место в коде:** `.hero-background` или можно добавить `<img>` в `.hero`

**Рекомендуемые варианты:**
1. **Абстрактная композиция** — геометрические формы, линии, конструктивистские элементы (чёрно-белое)
2. **Архивное фото** — старинная фотография модного показа начала XX века (сепия/чёрно-белое)
3. **Текстура ткани** — крупный план драпировки, складок, фактуры материала
4. **Силуэт** — силуэт платья на нейтральном фоне (минималистично)
5. **Абстрактный паттерн** — повторяющийся геометрический узор в стиле авангарда

**Стиль:** Минималистично, атмосферно, не перегружено деталями. Должно работать как фон для крупного текста.

## 📋 ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

### Размеры изображений:
- **Hero background:** 1920x1080px или больше (широкое горизонтальное)
- **Карточки личностей:** 800x1000px (вертикальное) или 800x800px (квадратное)
- **Детальный профиль hero:** 1600x900px (широкое горизонтальное)
- **Галерея работ:** 800x1000px (вертикальное) или 1000x800px (горизонтальное)

### Форматы:
- **Рекомендуется:** JPG (высокое качество, оптимизированный) или WebP
- **Для прозрачности:** PNG (если нужно)

### Оптимизация:
- Сжимайте изображения перед загрузкой (TinyPNG, ImageOptim)
- Используйте lazy loading (уже реализован в коде)
- Вес файла: не более 500KB для карточек, не более 1MB для hero

### Стиль обработки:
- **Чёрно-белые** или **приглушённые цвета** для портретов
- **Единая цветовая коррекция** для всех изображений
- **Высокий контраст** для читаемости текста поверх изображений
- **Грануляция/текстура** для архивного ощущения (опционально)

## 📝 КАК ДОБАВИТЬ ФОТО В КОД

### Для карточек личностей:
```html

<!-- СТАЛО: -->

```

### Для детального профиля:
```html

<div class="personality-detail-image-placeholder">Поль Пуаре</div>

<!-- СТАЛО: -->
<img src="assets/personalities/poiret-hero.jpg" alt="Поль Пуаре">
```

### Для галереи:
```html
<!-- БЫЛО: -->
<div class="gallery-placeholder">Работа Пуаре 1</div>

<!-- СТАЛО: -->

```

**Не забудьте:** Добавить CSS стили для `<img>` (уже есть в styles.css, раскомментируйте при необходимости).
